# 🌤 SpringBootOracle

> Spring Boot를 활용하여 WebSocket 채팅과 날씨 정보 조회 기능을 구현한 학습 프로젝트입니다.

---

## 📌 Overview

Spring Boot 기반 웹 애플리케이션 구조를 학습하고,
실시간 채팅 기능과 외부 Open API 연동을 경험하기 위해 제작한 프로젝트입니다.

---

## ⚙️ Tech Stack

| Category | Technology |
|----------|------------|
| Backend | Java, Spring Boot |
| Build Tool | Maven |
| Communication | WebSocket |
| External API | Weather API |
| Pattern | MVC |

---

## 🚀 Main Features

### 💬 Chat

- 채팅방 생성
- 채팅방 목록 조회
- WebSocket 기반 실시간 채팅

### 🌤 Weather

- 사용자 위치 기반 날씨 조회
- 외부 Open API 연동
- JSON 데이터 처리
